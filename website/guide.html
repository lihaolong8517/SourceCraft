使用教程

从下载安装到日常使用，这份完整教程将帮助您快速掌握 SourceCraft 多媒体下载工具的所有功能。

📋 系统要求

操作系统 Windows 10 / 11（64位）
处理器 Intel / AMD 64位处理器
内存 建议 4 GB 以上
磁盘空间 安装需约 500 MB，建议保留足够下载空间
网络 需要网络连接

1 下载并安装 SourceCraft

首先，从 SourceCraft 官方网站下载最新版安装包，然后按照安装引导完成安装。

⬇️ 下载安装包

  1. 访问 SourceCraft 官方网站
  2. 点击页面上的「立即下载」按钮
  3. 浏览器将自动开始下载安装包（.exe 文件）
  4. 等待下载完成

📦 安装软件

  1. 双击下载好的安装包（SourceCraft_Installer_vX.X.X.exe）
  2. 如果出现 Windows SmartScreen 提示，点击「更多信息」→「仍要运行」
  3. 选择安装路径（建议使用默认路径）
  4. 点击「安装」按钮，等待安装完成
  5. 安装完成后，桌面会出现 SourceCraft 快捷方式

💡 小贴士

安装包体积较大（约 400 MB），因为内置了 FFmpeg 引擎和 Playwright 浏览器环境。这些组件是确保视频下载和格式转换功能正常运行的必要依赖。

2 下载视频

SourceCraft 支持从多个平台下载视频。以下是基本下载流程：

🔗 获取视频链接

在浏览器中打开您想下载的视频页面，复制地址栏中的视频 URL 链接。

📋 粘贴链接到 SourceCraft

  1. 打开 SourceCraft 软件
  2. 在主界面的地址栏中粘贴视频链接（Ctrl+V）
  3. 软件会自动识别并解析视频信息

⬇️ 选择清晰度并下载

  1. 解析完成后，界面会显示可用的视频清晰度选项
  2. 选择您需要的清晰度（如 1080P、720P 等）
  3. 选择保存位置
  4. 点击「下载」按钮开始下载
  5. 下载进度会实时显示在任务列表中

💡 小贴士

如果直接粘贴链接无法解析，可以尝试使用内置浏览器直接访问视频页面。SourceCraft 的智能浏览器引擎能自动发现页面中的视频资源。

3 图片批处理

SourceCraft 内置的图片处理功能可以帮助您高效处理大量图片文件。

🖼️ 批量处理图片

  1. 在 SourceCraft 主界面选择「图片处理」功能模块
  2. 点击「添加图片」或拖拽图片文件到处理区域
  3. 选择处理操作：格式转换、尺寸调整、压缩质量等
  4. 设置输出参数（如目标格式、压缩比例）
  5. 点击「开始处理」，等待批量任务完成

4 格式转换

利用内置的 FFmpeg 引擎，SourceCraft 可以完成各种视频和音频格式转换。

🔄 转换视频 / 音频格式

  1. 在主界面选择「格式转换」功能
  2. 添加需要转换的视频或音频文件
  3. 选择目标输出格式（如 MP4、MP3、AVI 等）
  4. 根据需要调整编码参数（比特率、分辨率等）
  5. 点击「开始转换」

💡 小贴士

格式转换支持批量操作。您可以一次添加多个文件，统一设置输出参数后一键批量转换，大幅提升工作效率。

5 批量下载管理

当您需要下载多个视频时，可以使用批量下载功能。

📦 管理下载任务

  1. 将多个视频链接分行粘贴到地址栏
  2. SourceCraft 会自动识别每个链接并创建下载任务
  3. 在任务列表中可以查看每个任务的进度
  4. 支持暂停、继续、取消单个任务
  5. 所有任务完成后会收到通知
