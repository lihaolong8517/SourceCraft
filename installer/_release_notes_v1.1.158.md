## SourceCraft v1.1.158

### 新增：内置浏览器「媒体捕捉」全面升级（复刻 Video Download Helper）

- 全新捕获引擎：基于 Chrome DevTools Protocol 直接读取真实网络请求，完整保留 `Referer` / `Cookie` / `User-Agent` 等请求头，捕获覆盖 HLS(m3u8)、DASH(mpd)、MP4/WebM 直链、音视频分离流
- 站点适配器：B 站（WBI 签名）、VK、ok.ru、Facebook、Kick、Chaturbate、Twitcasting、Vimeo 等站点直接解析播放器数据，比单纯嗅探更稳
- 清单解析：自动读取 m3u8/mpd 的分辨率、码率、音轨、字幕与 DRM 信息，卡片直接显示「MP4 1080p」等清晰度标签
- 请求头回放：下载时把捕获到的请求头交给 yt-dlp，403/防盗链站点可直接下载；Cookie 冲突自动避让，失败自动回退
- 媒体卡片重做：封面（无封面自动从视频抽帧）、时长、清晰度徽标、格式选择、下载 / 下载为 / 仅音频 / 复制链接、下载进度与「停止」
- 悬停内联预览：鼠标移到卡片上自动静音循环播放 3~6 秒预览片段，移开自动暂停回封面；预览片段带缓存，重复悬停不重复生成
- 清空后可立即重新捕获：点「清空」后无需刷新页面，重新播放即可再次捕获
- 媒体捕获窗口新增「📌 置顶」开关：可选始终置顶或普通窗口，选择会被记住

### 修复

- 修复媒体捕捉窗口相关线程在销毁时未退出导致的崩溃（Qt5 qFatal，事件日志 `0xc0000409`）
- 修复悬停预览黑屏、闪现「预览失败」提示、tooltip 黑框遮挡画面
- 修复元数据回调把已抽好的真实封面覆盖成占位图

### 安装

下载 `SourceCraft_Installer_v1.1.158.exe` 运行安装即可，支持 Windows 10 / 11（64 位）。

> 提示：如下载速度较慢，请尝试使用 VPN 后重试。
